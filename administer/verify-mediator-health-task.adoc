= ONTAP Mediator 상태를 확인하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator가 정상적으로 실행 중인지 확인하십시오.



[[verify-the-service-status]]
== 서비스 상태를 확인하십시오

.단계
. ONTAP Mediator의 상태를 확인하십시오:
+
.. 다음 명령을 실행합니다.
+
[source, cli]
----
systemctl status ontap_mediator
----
+
[listing]
----
[root@mediator_host ~]# systemctl status ontap_mediator

Main PID: 286712 (uwsgi)

      ├─286716 /opt/netapp/lib/ontap_mediator/pyenv/bin/uwsgi --ini /opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini

----
.. SCST 서비스 상태를 확인하십시오:
+

NOTE: HTTPS만 지원하는 ONTAP Mediator 1.12 이상을 설치한 경우 SCST 패키지가 설치되지 않으므로 이 작업을 건너뛸 수 있습니다.

+
[source, cli]
----
systemctl status mediator-scst
----
+
[listing]
----
[root@mediator_host ~]# systemctl status mediator-scst

   Memory: 1.2M
   CGroup: /system.slice/mediator-scst.service

[root@mediator_host ~]#
----






[[confirm-the-listening-ports]]
== 수신 포트를 확인하십시오

. ONTAP Mediator에서 사용하는 포트를 확인하십시오:
+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
[listing]
----
[root@scspr1905507001 ~]# netstat -anlt | grep -E '3260|31784'

         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
----
