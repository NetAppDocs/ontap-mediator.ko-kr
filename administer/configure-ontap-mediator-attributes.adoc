= ONTAP Mediator 속성 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
인증서 관련 설정 및 구성 재정의 등 ONTAP Mediator 호스트 측 속성을 구성할 수 있습니다.



[[ontap-mediator-configurable-settings]]
== ONTAP Mediator 구성 가능 설정

ONTAP Mediator는 여러 구성 가능한 설정을 지원합니다. 이러한 설정의 기본값은  `low_space_threshold_mib: 10`읽기 전용 파일에 제공됩니다. 해당 파일의 위치는 다음과 같습니다.

`/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml`

 `ontap_mediator.user_config.yaml`에 입력된 모든 값은 기본값을 재정의하며 모든 ONTAP Mediator 업그레이드에서 유지됩니다.

 `ontap_mediator.user_config.yaml`을(를) 수정한 후 ONTAP Mediator를 다시 시작하십시오:

[source, cli]
----
systemctl restart ontap_mediator
----
이 섹션에서 설명하는 ONTAP Mediator 속성은 필요에 따라 수정할 수 있습니다.


NOTE: ONTAP Mediator 업그레이드 중에는 수정된 값이 유지되지 않으므로  `ontap_mediator.config.yaml`의 다른 기본값은 변경하지 않아야 합니다.

ONTAP Mediator의 속성을 수정하려면 필요한 변수를  `ontap_mediator.user_config.yaml` 파일에 복사하여 기본 설정을 재정의하면 됩니다.



[[install-third-party-ssl-certificates]]
== 타사 SSL 인증서를 설치하십시오

ONTAP Mediator 구성 파일을 수정하여 기본 자체 서명 인증서를 타사 SSL 인증서로 교체할 수 있습니다.

기본 제공되는 자체 서명 인증서를 타사 SSL 인증서로 교체하려면 다음 파일에서 특정 속성을 수정해야 합니다.

* `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.config.yaml`
* `/opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini`


이 파일들의 변수는 ONTAP Mediator에서 사용하는 인증서 파일을 제어하는 데 사용됩니다.

[role="tabbed-block"]
====
.ONTAP Mediator 1.9 이상 버전
--
다음 표에 나열된 기본 변수들이  `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.config.yaml` 파일에 포함되어 있습니다.

[cols="2*"]
|===
| 변수 | 경로 


| `cert_path` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator_server.crt` 


| `key_path` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator_server.key` 


| `ca_cert_path` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/intermediate.crt` 


| `ca_key_path` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/intermediate.key` 


| `ca_serial_path` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/intermediate.srl` 


| `cert_valid_days` | `1095` 


| `x509_passin_pwd` | `pass:ontap` 
|===
* `cert_valid_days`은(는) 클라이언트 인증서의 만료일을 설정하는 데 사용됩니다. 최대값은 3년(1095일)입니다.
* `x509_passin_pwd`는 서명된 클라이언트 인증서의 암호입니다.


다음 표에 나열된 기본 변수들이  `/opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini` 파일에 포함되어 있습니다.

| `mediator_key` | `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator_server.key`

[[configure-password-attack-protection]]
== 암호 공격 방지 구성

다음 설정은 무차별 대입 암호 추측 공격으로부터 보호 기능을 제공합니다.

이 기능을 활성화하려면  `window_seconds` 및  `retry_limit`에 값을 설정하십시오.

.예:
--
* 5분 동안 추측할 시간을 주고, 그 후 실패 횟수를 0으로 재설정하십시오:
+
`authentication_lock_window_seconds: 300`

* 지정된 시간 내에 5회 실패가 발생하면 계정을 잠급니다:
+
`authentication_retry_limit: 5`

* 각 시도를 거부하기 전에 발생하는 지연 시간을 설정하여 공격 속도를 늦춤으로써 무차별 대입 암호 추측 공격의 영향을 줄이십시오.
+
`authentication_failure_delay_seconds: 5`

+
....
authentication_failure_delay_seconds: 0   # seconds (float) to delay failed auth attempts prior to response, 0 = no delay
authentication_lock_window_seconds: null  # seconds (int) since the oldest failure before resetting the retry counter, null = no window
authentication_retry_limit: null          # number of retries to allow before locking API access, null = unlimited
....


--


[[configure-password-complexity-rules]]
== 암호 복잡성 규칙 구성

다음 필드는 ONTAP Mediator API 사용자 계정의 암호 복잡성 규칙을 제어합니다.

....
password_min_length: 8

password_max_length: 64

password_uppercase_chars: 0    # min. uppercase characters

password_lowercase_chars: 1    # min. lowercase character

password_special_chars: 1      # min. non-letter, non-digit

password_nonletter_chars: 2    # min. non-letter characters (digits, specials, anything)
....
여유 공간 임계값과 예약된 로그 공간 등 ONTAP Mediator 디스크 및 로그 공간 설정을 구성합니다.



[[configure-the-free-space-threshold]]
== 여유 공간 임계값 구성

 `/opt/netapp/lib/ontap_mediator` 디스크에 필요한 여유 공간을 제어하는 설정이 있습니다.

공간이 설정된 임계값보다 낮으면 서비스는 경고 이벤트를 발생시킵니다.

....
low_space_threshold_mib: 10
....


[[configure-reserved-log-space]]
== 예약된 로그 공간 구성

 `RESERVE_LOG_SPACE` 기능은 특정 설정으로 제어됩니다. 기본적으로 ONTAP Mediator 설치 시 로그를 위한 별도의 디스크 공간이 생성됩니다. 설치 프로그램은 ONTAP Mediator 로깅 전용으로 사용될 총 700MB 디스크 공간의 새로운 고정 크기 파일을 생성합니다.

이 기능을 비활성화하고 기본 디스크 공간을 사용하려면 다음 단계를 수행하십시오:

. 다음 파일에서 RESERVE_LOG_SPACE 값을 1에서 0으로 변경하십시오:
+
`/opt/netapp/lib/ontap_mediator/tools/mediator_env`

+
.. 다음 명령을 실행합니다.
+
[source, cli]
----
cat /opt/netapp/lib/ontap_mediator/tools/mediator_env | grep "RESERVE_LOG_SPACE"
----
+
....
RESERVE_LOG_SPACE=0
....
.. ONTAP Mediator를 재시작하십시오:
+
[source, cli]
----
systemctl restart ontap_mediator
----




--
해당 기능을 다시 활성화하려면 값을 0에서 1로 변경하고 Mediator를 다시 시작하십시오.


NOTE: 디스크 공간을 전환해도 기존 로그는 삭제되지 않습니다. 이전의 모든 로그는 백업된 후, 디스크 공간을 전환하고 Mediator를 재시작하면 현재 디스크 공간으로 이동됩니다.
