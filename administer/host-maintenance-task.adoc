= ONTAP Mediator의 호스트 운영 체제 유지 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
최적의 성능을 달성하려면 ONTAP Mediator의 호스트 OS를 정기적으로 유지 관리해야 합니다.



[[reboot-the-host]]
== 호스트를 재부팅하십시오

클러스터가 정상 상태일 때만 호스트를 재부팅하십시오. ONTAP Mediator가 오프라인 상태인 동안에는 클러스터가 장애에 대응할 수 없습니다. 재부팅하기 전에 유지 관리 시간을 설정하십시오.

ONTAP Mediator는 재부팅 중에 자동으로 재개되어 이전에 구성된 ONTAP 클러스터와의 관계를 다시 설정합니다.



[[host-package-updates]]
== 호스트 패키지 업데이트

커널을 제외한 모든 라이브러리 또는 yum 패키지를 업데이트하십시오. 변경 사항을 적용하기 위해 필요한 경우 호스트를 재부팅하십시오. 호스트를 재부팅하기 전에 서비스 기간을 예약하십시오.

 `yum-utils` 패키지를 설치하는 경우  `needs-restarting` 명령을 사용하여 패키지 변경 사항으로 인해 재부팅이 필요한지 확인하십시오.

ONTAP Mediator 종속성 업데이트 후 변경 사항이 즉시 적용되지 않으므로 재부팅하십시오.



[[upgrade-the-host-os-kernel]]
== 호스트 OS 커널을 업그레이드하십시오

SCST는 사용 중인 커널에 맞게 컴파일되어야 합니다. OS를 업데이트하려면 유지보수 시간을 예약해야 합니다.

.시작하기 전에
ONTAP Mediator와 함께 SCST 패키지를 설치할 경우 다음과 같은 요구 사항이 적용됩니다.

* 커널을 제외한 모든 라이브러리 패키지를 업데이트할 수 있지만, ONTAP Mediator에 변경 사항을 적용하려면 재부팅해야 할 수 있습니다. 재부팅이 필요한 경우 다운타임을 예약하십시오.
* OS 커널을 최신 상태로 유지해야 합니다. link:../release-notes/support-matrix.html#scst-support-matrix["ONTAP Mediator 버전 매트릭스"]에 나열된 지원되는 버전으로 커널 코어를 업그레이드하십시오. 시스템을 재부팅해야 하므로 운영 중단에 대비하여 유지보수 윈도우를 계획하십시오.
+
** 재부팅하기 전에 SCST 커널 모듈을 제거한 다음, 재부팅 후에 다시 설치하십시오.
** 커널 OS 업그레이드를 시작하기 전에 재설치할 지원되는 버전의 SCST를 준비하십시오.





NOTE: HTTPS만 지원하는 ONTAP Mediator 1.12 이상을 설치한 경우 SCST 패키지가 설치되지 않으며 ONTAP Mediator에 영향을 주지 않고 호스트 OS 커널을 업그레이드할 수 있습니다. 업그레이드 지침은 호스트 OS 설명서를 참조하십시오.

.단계
호스트 운영체제 커널을 업그레이드하려면 다음 단계를 따르십시오.


NOTE: 커널을 업그레이드하기 전에 운영 체제 및 ONTAP Mediator 버전이 호환되는지 확인하십시오. 지원되는 버전은 link:../release-notes/support-matrix.html#os-support-matrix["OS 지원 매트릭스"]을(를) 참조하십시오.

. ONTAP Mediator를 중지하십시오.
. SCST 패키지를 제거하십시오. <<호스트 유지보수 수행>>을 참조하십시오. (SCST는 업그레이드 메커니즘을 제공하지 않습니다.)
. 운영 체제를 업그레이드하고 재부팅하십시오.
. SCST 패키지를 다시 설치하십시오.
. ONTAP Mediator를 다시 활성화하십시오.




[[perform-host-maintenance]]
== 호스트 유지보수 수행

가상 머신 커널을 업그레이드하면 SCST 모듈과의 호환성 문제가 발생할 수 있습니다. SCST를 수동으로 제거한 후 다시 설치하십시오.


NOTE: HTTPS만 지원하는 ONTAP Mediator 1.12 이상을 설치한 경우 SCST 패키지가 설치되지 않으므로 이 작업을 건너뛸 수 있습니다.

[[step-2-install-scst]]
=== 2단계: SCST 설치

SCST를 수동으로 설치하려면 설치된 ONTAP Mediator 버전에 사용되는 SCST tar 번들이 필요합니다(<<scst-bundle-table,SCST 테이블>> 참조).

.이 작업 정보
* ONTAP Mediator를 설치하기 전에 이 단계를 수행하십시오. 사용 중인 SCST 버전이 ONTAP Mediator 설치 프로그램에 포함된 버전보다 최신인 경우 설치 프로그램은 이 단계를 건너뜁니다.
* 경우에 따라 업그레이드된 운영 체제에 SCST를 기본 설치하는 과정에서 업그레이드된 운영 체제에 필요한 패치 때문에 설치가 실패할 수 있습니다.
+
ONTAP Mediator 1.12.1부터 설치가 실패하는 경우,  `/usr/local/bin/mediator_repair_scst`에 있는 SCST 복구 툴을 사용하여 설치를 복구할 수 있습니다.

+
업그레이드된 운영 체제에 패치가 필요한 경우, 해당 도구에는 ONTAP Mediator 패키지에 포함된 SCST 버전에 맞는 패치가 들어 있습니다. 이  `mediator_repair_scst`도구는 메인 설치 프로그램과는 별개의 독립 실행형 툴이며 ONTAP Mediator  `tgz`파일 내에 포함되어 있습니다. ONTAP Mediator의 설치 또는 업그레이드 경로에는 영향을 미치지 않습니다.



.단계
.  `scst` 디렉터리에서 다음 설치 명령을 실행하십시오:
+
.. `make 2release`
.. `make scst_install`
.. `make usr_install`
.. `make iscsi_install`
.. `make scstadm_install`
.. `depmod`
+
[NOTE]
====
처음 설치하는 경우 ONTAP Mediator를 사전 설치하려면 다음 단계로 진행하기 전에 다음 명령을 실행하십시오.

`mkdir -p /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys`

====
.. `cp scst/src/certs/scst_module_key.der /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/`
.. `patch /etc/init.d/scst < /opt/netapp/lib/ontap_mediator/systemd/scst.patch`
+

NOTE: 최초 설치 시 ONTAP Mediator보다 먼저 SCST를 사전 설치한 경우 이 단계를 건너뛰십시오. 설치 프로그램이 관련 SCST 패치를 적용합니다.



. 선택적으로, 보안 부팅이 활성화된 경우 재부팅하기 전에 다음 단계를 수행하십시오:
+
..  `scst_vdisk`,  `scst` 및  `iscsi_scst` 모듈에 대한 각 파일 이름을 결정하십시오:
+
....
[root@localhost ~]# modinfo -n scst_vdisk
[root@localhost ~]# modinfo -n scst
[root@localhost ~]# modinfo -n iscsi_scst
....
.. 커널 릴리스를 확인하십시오:
+
....
[root@localhost ~]# uname -r
....
.. 커널로 각 모듈 파일에 서명하십시오:
+
....
[root@localhost ~]# /usr/src/kernels/<KERNEL-RELEASE>/scripts/sign-file \sha256 \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.priv \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der \
_module-filename_
....
.. 펌웨어와 함께 UEFI 키를 설치하십시오.
+
UEFI 키 설치 지침은 다음 위치에 있습니다:

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/README.module-signing`

+
생성된 UEFI 키는 다음 위치에 있습니다:

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der`



. 시스템을 재부팅하십시오:
+
`reboot`





[[host-changes-to-the-hostname-or-ip]]
== 호스트 이름 또는 IP에 대한 호스트 변경 사항

.이 작업 정보
* ONTAP Mediator를 설치한 Linux 호스트에서 이 작업을 수행하십시오.
* ONTAP Mediator를 설치한 후 호스트 이름이나 IP 주소가 변경되어 자체 서명된 인증서가 더 이상 유효하지 않은 경우에만 이 작업을 수행하십시오.
* 임시 자체 서명 인증서를 신뢰할 수 있는 타사 인증서로 교체한 후에는 이 작업을 사용하여 인증서를 다시 생성하지 _않습니다_. 자체 서명 인증서가 없는 경우 이 절차를 사용할 수 없습니다.


.단계
현재 호스트에 대한 임시 자체 서명 인증서를 생성합니다:

. ONTAP Mediator를 재시작하십시오:
