= ONTAP Mediator를 기존 CA 인증서의 일반 이름으로 전환하세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator 1.13부터 자체 서명된 CA 인증서의 일반 이름에 설치별 식별자가 포함됩니다. ONTAP Mediator 인스턴스를 이 식별자를 인식하지 못하는 ONTAP 릴리스와 페어링해야 하는 경우, 기존의 고정된 일반 이름으로 전환하십시오.

기본적으로 ONTAP Mediator CA 인증서에는 일반 이름에 설치별 식별자가 포함됩니다(예:  `ONTAP Mediator CA 1a2b3c4d`). 이를 통해 동일한 ONTAP 클러스터에 여러 ONTAP Mediator 인스턴스를 등록할 수 있습니다. ONTAP은 주체 이름은 같지만 키가 다른 두 개의 CA 인증서 설치를 거부하기 때문입니다.

다음 ONTAP 릴리스에서는 일반 이름을 정확히 일치시켜 ONTAP Mediator CA를 찾으며 식별자는 인식하지 않습니다:

* ONTAP 9.11.1 및 이전 버전
* 9.12.1P15, 9.13.1P12, 9.14.1P8 및 9.15.1P2 이전의 ONTAP 패치 릴리스


ONTAP Mediator 인스턴스가 이러한 릴리스 중 하나와 페어링되어야 하는 경우 기존의 고정된 공통 이름을 사용하십시오.

.이 작업 정보
* ONTAP Mediator를 설치한 Linux 호스트에서 이 작업을 수행하십시오.
* 기존 공통 이름이 유효한 동안에는 ONTAP 클러스터당 하나의 ONTAP Mediator 인스턴스만 등록할 수 있습니다.


.단계
. 다음 줄을  `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml` 파일에 추가하십시오. 이 파일은 ONTAP Mediator 업그레이드 시에도 유지됩니다.
+
`'generate_unique_ca_name': false`

. 인증서를 다시 생성하십시오:
+
[source, cli]
----
[root@localhost ~]# cd /opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/; ./make_self_signed_certs.sh overwrite
----
. 서비스를 재시작하십시오:
+
[source, cli]
----
[root@localhost ~]# sudo systemctl restart ontap_mediator
----
. 자체 서명된 CA 인증서가 사용되는 모든 페어링된 ONTAP 클러스터에서 다음 작업을 수행하십시오:
+
.. ONTAP Mediator를 제거합니다.
.. 이전에 설치한 CA 인증서를 삭제하십시오.
.. 재생성된  `root_ca.crt` 및  `intermediate.crt` 인증서를 설치하십시오.
.. ONTAP Mediator를 다시 추가하십시오.
+

CAUTION: 재생성은 항상 새 키를 생성하므로 먼저 기존 CA 인증서를 삭제해야 합니다. 기존 인증서를 그대로 두면 ONTAP은 더 이상 서버 인증서에 서명하지 않는 CA를 유지하게 됩니다. 최신 ONTAP 버전 또한 새 인증서와 기존 인증서의 주체 이름이 동일하기 때문에 교체 CA 인증서 설치를 거부합니다.
