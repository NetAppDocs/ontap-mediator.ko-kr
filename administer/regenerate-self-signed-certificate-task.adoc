= ONTAP Mediator 호스트용 임시 자체 서명 인증서를 다시 생성합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 이름이나 IP 주소 변경으로 기존 인증서가 무효화될 경우 현재 호스트에 대한 임시 자체 서명 인증서를 다시 생성합니다.


NOTE: 이 절차는 ONTAP Mediator 1.7 이상 버전이 실행되는 시스템에서만 지원됩니다.

.이 작업 정보
* ONTAP Mediator를 설치한 Linux 호스트에서 이 작업을 수행하십시오.
* ONTAP Mediator를 설치한 후 호스트의 호스트 이름이나 IP 주소가 변경되어 생성된 자체 서명 인증서가 더 이상 유효하지 않게 된 경우에만 이 작업을 수행할 수 있습니다.
* 임시 자체 서명 인증서를 신뢰할 수 있는 타사 인증서로 교체한 후에는 이 작업을 사용하여 인증서를 다시 생성해서는 _안_ 됩니다. 자체 서명 인증서가 없으면 이 절차가 실패합니다.


.단계
현재 호스트에 대한 새 임시 자체 서명 인증서를 다시 생성하려면 다음 단계를 수행하십시오:

. ONTAP Mediator를 재시작하십시오:
+
`./make_self_signed_certs.sh overwrite`
