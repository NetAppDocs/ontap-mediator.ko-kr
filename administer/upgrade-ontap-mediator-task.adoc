= ONTAP Mediator 업그레이드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 OS를 업그레이드하지 않고 ONTAP Mediator를 최신 버전으로 업그레이드하려면 새 버전의 설치 패키지를 다운로드하고 ONTAP Mediator가 이미 설치된 호스트에서 설치 프로그램을 실행하십시오.


NOTE: 호스트 OS를 새 릴리스로 업그레이드하고 그 과정의 일부로 ONTAP Mediator를 다시 설치하거나 업그레이드해야 하는 경우, 대신 link:upgrade-host-os-mediator-task.html["호스트 운영 체제 및 ONTAP Mediator를 업그레이드하십시오."]을(를) 참조하십시오.

.시작하기 전에
* 호스트가 호스트, 방화벽 및 OS 요구 사항을 포함하여 link:../install/prepare-install.html["ONTAP Mediator 설치 준비"]에 설명된 필수 조건을 충족하는지 확인하십시오.
* 새 버전의 설치 패키지를 다운로드하십시오. link:../install/download-install-pkg-task.html["ONTAP Mediator 설치 패키지를 다운로드하십시오"]을(를) 참조하십시오.
* NetApp은 새 설치 패키지의 코드 서명을 확인할 것을 권장합니다. link:../install/verify-code-signature-task.html["ONTAP Mediator 설치 패키지의 코드 서명을 확인하십시오."]을(를) 참조하십시오.


.이 작업 정보
ONTAP Mediator를 업그레이드하기 전에 다음 정보를 검토하십시오.

* ONTAP Mediator를 최신 버전으로 업그레이드해야 합니다. 이전 버전도 모든 ONTAP 릴리스와 호환되지만, 최신 버전에는 타사 구성 요소에 대한 보안 패치가 포함되어 있습니다.
* SCST 패키지가 포함된 새로운 ONTAP Mediator 버전으로 업그레이드할 경우, 설치 프로그램은 더 높은 버전이 없는 한 권장 SCST 버전으로 자동 업그레이드합니다. 더 높은 SCST 버전을 수동으로 설치하는 방법에 대한 지침은 link:host-maintenance-task.html["ONTAP Mediator의 호스트 운영 체제 유지 관리"]을 참조하십시오. 지원되는 버전은 link:../release-notes/support-matrix.html#scst-support-matrix["SCST 지원 매트릭스"]을 참조하십시오.


[NOTE]
====
* 업그레이드가 실패하면 ONTAP Mediator의 최신 버전을 사용해 봐야 할 수도 있습니다.
* 2025년 6월 15일부터는 해당 코드 서명 인증서가 만료되었으므로 ONTAP Mediator 1.9 및 1.8을 설치하거나 업그레이드할 수 없습니다. 업그레이드에 실패할 경우 대신 ONTAP Mediator 1.9.1 패치 버전을 사용하십시오.


====
* ONTAP 9.19.1 및 ONTAP Mediator 1.12 버전부터는 iSCSI 및 HTTPS 지원 또는 HTTPS만 지원하는 ONTAP Mediator 설치 옵션을 선택할 수 있습니다. HTTPS만 지원하는 ONTAP Mediator를 설치하는 경우 SCST 패키지는 설치되지 않습니다.
* SCST가 설치된 ONTAP Mediator 1.11 이하 버전에서 업그레이드할 때 HTTPS 전용 옵션을 선택하면 SCST 패키지가 제거되고 새 ONTAP Mediator 버전에는 SCST 패키지가 포함되지 않습니다.
* ONTAP Mediator를 사용하여 여러 MetroCluster IP 구성을 모니터링하려는 경우 지원 여부는 Mediator 유형, ONTAP 버전 및 운영 체제에 따라 다릅니다. 자세한 내용은 link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["ONTAP Mediator를 사용하여 여러 MetroCluster IP 구성을 모니터링합니다"^]을 참조하십시오.
* HTTPS만 지원하는 ONTAP Mediator 설치는 다음과 같은 사용 사례에 한해 지원됩니다.
+
** ONTAP Mediator를 SnapMirror 액티브 동기화 클러스터 모니터링에만 사용할 계획입니다.
** ONTAP Mediator를 HTTPS로 구성하여 하나 이상의 MetroCluster IP 구성을 모니터링할 계획입니다.


* 다음 시나리오에서는 ONTAP Mediator를 iSCSI 및 HTTPS 지원과 함께 설치해야 합니다.
+
** 하나 이상의 MetroCluster IP 구성을 모니터링하기 위해 ONTAP Mediator를 iSCSI로 구성할 계획입니다.




* 기존 ONTAP Mediator 설치 환경에서 설치 프로그램을 실행하면 현재 버전을 감지하고 업그레이드를 확인하라는 메시지가 표시됩니다:
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* 업그레이드 과정의 일부로 설치 프로그램은 ONTAP Mediator 소프트웨어를 업그레이드하기 전에 업그레이드 전 구성의 지원 번들을 캡처하고 데이터베이스를 마이그레이션합니다.
* 자동화 사용 사례의 경우,  `./ontap-mediator-1.12.1/ontap-mediator-1.12.1 -y` 명령을 사용하여 설치 프로그램 프롬프트를 건너뛸 수 있습니다.


.단계
. 새 버전의 설치 프로그램을 실행하고 필요에 따라 프롬프트에 응답하십시오:
+
[source, cli]
----
./ontap-mediator-1.12.1/ontap-mediator-1.12.1
----
+
[NOTE]
====
업그레이드 중 서명 확인을 건너뛰려면 
`./ontap-mediator-1.12.1/ontap-mediator-1.12.1 --skip-code-signature-check` 명령을 사용하십시오.

====
+
설치 프로그램은 기존 설치를 감지하고 업그레이드하라는 메시지를 표시한 다음 필요한 패키지를 설치하고 구성을 마이그레이션합니다.
