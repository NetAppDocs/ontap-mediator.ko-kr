= ONTAP Mediator 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
필요한 경우 ONTAP에서 연결을 해제한 후 ONTAP Mediator를 제거하십시오.

.시작하기 전에
ONTAP Mediator를 제거하기 전에 ONTAP에서 연결을 해제해야 합니다.

.이 작업 정보
ONTAP Mediator를 설치한 Linux 호스트에서 이 작업을 수행하십시오.

이 명령에 접근할 수 없는 경우, 다음 예시와 같이 전체 경로를 사용하여 명령을 실행해야 할 수 있습니다:

`/usr/local/bin/uninstall_ontap_mediator`

.단계
. ONTAP Mediator를 제거하십시오:
+
[source, cli]
----
uninstall_ontap_mediator
----
+
....
 [root@mediator-host ~]# uninstall_ontap_mediator

 ONTAP Mediator: Self Extracting Uninstaller

 + Removing ONTAP Mediator. (Log: /tmp/ontap_mediator.GmRGdA/uninstall_ontap_mediator/remove.log)
 + Remove successful.
 [root@mediator-host ~]#
....
