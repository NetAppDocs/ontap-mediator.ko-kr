= ONTAP Mediator 빠른 시작
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
ONTAP Mediator를 시작하려면 소프트웨어를 설치하고 ONTAP 환경과 연동되도록 구성해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] ONTAP Mediator 설치
[role="quick-margin-para"]
시스템에서 link:install/workflow-summary.html["ONTAP Mediator를 설치합니다"] 필요한 모든 종속성이 충족되는지 확인하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] ONTAP Mediator 설치를 확인하십시오
[role="quick-margin-para"]
link:install/verify-install-task.html["ONTAP Mediator 설치가 성공적으로 완료되었는지 확인하십시오."] 서비스 상태를 확인하고 로그에서 오류나 경고가 있는지 검토하여 문제를 해결할 수 있습니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3"] ONTAP 환경에 맞게 ONTAP Mediator를 구성하십시오
[role="quick-margin-para"]
link:use-mediator-snapmirror-metrocluster-task.html["MetroCluster IP, SnapMirror 활성 동기화 또는 둘 다를 위해 ONTAP Mediator를 사용하십시오."]하기를 원하는지 여부에 따라 적절한 구성 단계를 따라 필요한 모든 설정이 올바르게 적용되도록 하십시오.
