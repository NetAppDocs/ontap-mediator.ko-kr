= ONTAP Mediator의 새로운 기능
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
각 릴리스마다 ONTAP Mediator에 대한 새로운 기능 향상이 제공됩니다.


NOTE: OS 및 SCST 버전 정보는 link:support-matrix.html["지원 매트릭스"]을(를) 참조하십시오.

[cols="25,75"]
|===


| ONTAP Mediator 버전 | 향상된 기능 


 a| 
1.12.1
 a| 
* RHEL 지원:
+
** 호환: 10.1 및 9.7.
** 권장 사항: 10.2, 10.0, 9.8, 9.6, 9.4, 8.10.


* Rocky Linux 10.2, 9.8 및 8.10을 지원합니다.
* rhck 및 uek 커널을 모두 사용하는 Oracle Linux 10.1 및 9.8 지원.
* ONTAP Mediator 1.12.1 및 ONTAP 9.19.1부터 HTTPS로 구성된 단일 ONTAP Mediator 인스턴스는 다음 구성을 동시에 모니터링할 수 있습니다.
+
** 8코어 CPU와 최소 16GB RAM을 갖춘 호스트에 설치하는 경우 최대 10개의 4노드 또는 5개의 8노드 MetroCluster IP 구성을 사용할 수 있습니다. link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["ONTAP Mediator를 사용하여 여러 MetroCluster IP 구성을 모니터링합니다"^]을(를) 참조하십시오.
** 2코어 CPU를 탑재한 호스트에 설치된 경우, 4노드 MetroCluster IP 구성 하나와 SnapMirror 활성 동기화 피어 관계 하나. link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html#ontap-mediator["SnapMirror 활성 동기화를 위해 ONTAP Mediator를 구성합니다."^]을(를) 참조하십시오.


* 손상된 SCST 설치를 복구하는 새로운 도구가 포함되어 있습니다. ONTAP Mediator를 설치한 후 해당 도구를 다음 위치에서 찾을 수 있습니다 `/usr/local/bin/mediator_repair_scst`. OS 업그레이드 후, 업그레이드된 OS에 기본 SCST 패키지에 포함되지 않은 SCST 패치가 필요한 경우 이 도구를 사용할 수 있습니다.

* RHEL 지원:

** 호환: 10.1 및 9.7.
** 권장 사항: 10.2, 10.0, 9.8, 9.6, 9.4, 8.10.


* Rocky Linux 10.2, 9.8 및 8.10을 지원합니다.
* rhck 및 uek 커널을 모두 사용하는 Oracle Linux 10.1 및 9.7 지원.
* ONTAP 9.19.1 및 ONTAP Mediator 1.12 버전부터 MetroCluster IP 구성에서 HTTPS를 사용하여 통신하는 ONTAP Mediator를 구성할 수 있습니다. HTTPS는 SSL/TLS를 사용하여 전체 세션을 암호화함으로써 보안을 강화합니다. HTTPS만 지원하도록 ONTAP Mediator를 설치할 수도 있습니다. 이 설치 방법을 사용하는 경우 SCST 패키지는 설치되지 않습니다. link:../install/prepare-install.html#https-iscsi-installation["ONTAP Mediator의 HTTPS 및 iSCSI 설치 옵션에 대해 자세히 알아보십시오"].
