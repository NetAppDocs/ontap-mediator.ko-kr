= SnapMirror 활성 동기화 및 MetroCluster IP를 위해 ONTAP Mediator를 사용하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
ONTAP Mediator는 ONTAP 클러스터와는 별도의 제3 장애 도메인에 있는 Linux 호스트에서 실행되며, 고가용성(HA) 메타데이터를 위한 영구적이고 펜싱된 저장소를 제공합니다. ONTAP은 이 저장소와 Mediator의 노드 상태 조회 및 핑 프록시 기능을 사용하여 SnapMirror 활성 동기화 관계 및 MetroCluster IP 구성을 모니터링합니다.


NOTE: 이 문서는 온프레미스 버전의 ONTAP Mediator에 대한 내용입니다. ONTAP 9.17.1부터 사용 가능한 ONTAP Cloud Mediator에 대한 자세한 내용은 link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html["SnapMirror 액티브 싱크 문서"^]를 참조하십시오.



[[monitor-snapmirror-active-sync-relationships]]
== SnapMirror 활성 동기화 관계를 모니터링합니다.

SnapMirror active sync는 일관성 그룹의 운영 및 미러 복사본에 대한 수동 감시자로 ONTAP Mediator를 사용합니다. 네트워크 분할이 발생하거나 한 복사본을 사용할 수 없게 되면 SnapMirror active sync는 ONTAP Mediator에 쿼리를 보내 어떤 복사본이 계속해서 I/O를 처리할지 결정하고, 다른 복사본의 I/O 처리를 중단합니다.

ONTAP 9.8부터는 모든 버전의 ONTAP Mediator를 사용하여 SnapMirror 활성 동기화 관계를 모니터링할 수 있습니다.


NOTE: 단일 ONTAP Mediator 인스턴스가 모니터링할 수 있는 SnapMirror 활성 동기화 클러스터 쌍 수에 대한 제한 사항은 link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/limits-reference.html["ONTAP SnapMirror 활성 동기화에 대한 오브젝트 제한"^]을(를) 참조하십시오.

link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html["SnapMirror 활성 동기화를 위해 ONTAP Mediator를 구성합니다."^]



[[monitor-metrocluster-ip-configurations]]
== MetroCluster IP 구성을 모니터링합니다

MetroCluster IP 구성에서 ONTAP Mediator는 MetroCluster 노드에 대한 상태 정보를 메일박스 LUN에 저장하고 재해 또는 특정 장애 시나리오 발생 시 Mediator 지원 자동 비계획 스위치오버(MAUSO)를 통해 노드를 지원합니다.

ONTAP 9.19.1 및 ONTAP Mediator 1.12부터 통신에 HTTPS를 사용하는 ONTAP Mediator를 구성하여 MetroCluster IP 구성을 모니터링할 수 있습니다. iSCSI 프로토콜로 ONTAP Mediator를 구성하는 경우, 모든 버전의 ONTAP Mediator를 사용하여 MetroCluster IP 구성을 모니터링할 수 있습니다.


NOTE: 단일 ONTAP Mediator 인스턴스가 모니터링할 수 있는 MetroCluster IP 구성 수에 대한 제한 사항은 link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["ONTAP Mediator를 사용하여 여러 MetroCluster IP 구성을 모니터링합니다"^]을(를) 참조하십시오.

link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html["MetroCluster IP 구성을 위한 ONTAP Mediator 구성"^]
