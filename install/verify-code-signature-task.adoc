= ONTAP Mediator 코드 서명을 확인하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp은 설치 전에 ONTAP Mediator 코드 서명을 확인할 것을 권장합니다. 이 단계는 선택 사항입니다.

.시작하기 전에
ONTAP Mediator 코드 서명을 확인하기 전에 시스템이 이러한 요구 사항을 충족하는지 확인하십시오.

[NOTE]
====
* 2025년 6월 15일부터는 코드 서명 확인 인증서가 만료되었으므로 ONTAP Mediator 1.9 및 1.8을 설치하거나 업그레이드할 수 없습니다. 대신 ONTAP Mediator 1.10 이상을 설치하거나 업그레이드하십시오.
* 시스템이 아래 요구 사항을 충족하지 않는 경우 검증 절차가 필요하지 않으며 바로 link:install-mediator-pkg-task.html["ONTAP Mediator 설치 패키지를 설치하십시오."](으)로 이동할 수 있습니다.


====
* 기본 검증을 위한 openssl 버전 1.0.2~3.0
* 타임스탬핑 기관(TSA) 작업을 위한 openssl 버전 1.1.0 이상
* OCSP 검증을 위한 공용 인터넷 접속


다운로드 패키지에는 다음 파일이 포함되어 있습니다:

[cols="50,50"]
|===


| 파일 | 설명 


 a| 
`ONTAP-Mediator-production.pub`
 a| 
서명을 확인하는 데 사용되는 공개 키



 a| 
`csc-prod-chain-ONTAP-Mediator.pem`
 a| 
공개 인증 기관(CA)의 신뢰 체인



 a| 
`csc-prod-ONTAP-Mediator.pem`
 a| 
키를 생성하는 데 사용된 인증서



 a| 
`ontap-mediator-1.12.1`
 a| 
버전 1.12용 제품 설치 실행 파일



 a| 
`ontap-mediator-1.12.1.sig`
 a| 
SHA-256 해시 후 csc-prod 키를 사용하여 RSA 서명된 설치 프로그램 서명



 a| 
`ontap-mediator-1.12.1.sig.tsr`
 a| 
OCSCP에서 설치자 서명에 사용하기 위한 취소 요청



 a| 
`ontap-mediator-1.12.1.tsr`
 a| 
타임스탬프 서명 요청 파일



 a| 
`tsa-prod-ONTAP-Mediator.pem`
 a| 
TSR에 대한 공개 인증서



 a| 
`tsa-prod-chain-ONTAP-Mediator.pem`
 a| 
TSR에 대한 공개 인증서 CA 체인

|===
.단계
. 온라인 인증서 상태 프로토콜(OCSP)을 사용하여  `csc-prod-ONTAP-Mediator.pem`에서 인증서 폐지 여부를 확인하십시오.
+
.. 인증서의 OCSP URL을 찾으십시오. 개발자 인증서에는 URI가 제공되지 않을 수 있습니다:
+
[source, cli]
----
openssl x509 -noout -ocsp_uri -in csc-prod-chain-ONTAP-Mediator.pem
----
.. 인증서에 대한 OCSP 요청을 생성합니다.
+
[source, cli]
----
openssl ocsp -issuer csc-prod-chain-ONTAP-Mediator.pem -CAfile csc-prod-chain-ONTAP-Mediator.pem -cert csc-prod-ONTAP-Mediator.pem  -reqout req.der
----
.. OCSP 요청을 보내려면 OCSP 관리자에 연결하십시오:
+
[source, cli]
----
openssl ocsp -issuer csc-prod-chain-ONTAP-Mediator.pem -CAfile csc-prod-chain-ONTAP-Mediator.pem -cert csc-prod-ONTAP-Mediator.pem  -url ${ocsp_uri} -resp_text -respout resp.der -verify_other csc-prod-chain-ONTAP-Mediator.pem
----


. 로컬 호스트에 대해 CSC의 신뢰 체인 및 만료 날짜를 확인하십시오:
+
[source, cli]
----
openssl verify
----
+

NOTE: PATH에 있는  `openssl` 버전에는 유효한  `cert.pem`(자체 서명되지 않음)가 있어야 합니다.

+
[source, cli]
----
openssl verify -untrusted csc-prod-chain-ONTAP-Mediator.pem -CApath ${OPENSSLDIR} csc-prod-ONTAP-Mediator.pem
openssl verify -untrusted tsa-prod-chain-ONTAP-Mediator.pem -CApath ${OPENSSLDIR} tsa-prod-ONTAP-Mediator.pem
----
+
코드 서명 확인 인증서 또는 타임스탬프 인증서가 만료되었거나 유효하지 않은 경우 명령이 실패합니다. ONTAP Mediator의 최신 버전을 다운로드하십시오.

. 관련 인증서를 사용하여  `ontap-mediator-1.12.1.sig.tsr` 및  `ontap-mediator-1.12.1.tsr` 파일을 확인하십시오.
+
[role="tabbed-block"]
====
.OpenSSL 3.x
--
[source, cli]
----
openssl ts -verify -data ontap-mediator-1.12.1.sig -in ontap-mediator-1.12.1.sig.tsr -CAfile tsa-prod-chain-ONTAP-Mediator.pem -untrusted tsa-prod-ONTAP-Mediator.pem
----
--
.OpenSSL 1.x
--
[source, cli]
----
openssl ts -verify -data ontap-mediator-1.12.1 -in ontap-mediator-1.12.1.tsr -CAfile tsa-prod-chain-ONTAP-Mediator.pem -partial_chain
----
--
====
+

NOTE: `.tsr` 파일에는 설치 프로그램 및 코드 서명과 관련된 타임스탬프 응답이 포함되어 있습니다. 처리 과정에서 타임스탬프에 TSA의 유효한 서명이 있는지, 그리고 입력 파일이 변경되지 않았는지 확인합니다. 사용자의 컴퓨터는 로컬에서 검증을 수행합니다. TSA 서버에 액세스할 필요가 없습니다.

. 서명을 키와 대조하여 확인합니다:
+
[source, cli]
----
openssl -dgst -verify
----
+
[source, cli]
----
openssl dgst -sha256 -verify ONTAP-Mediator-production.pub -signature ontap-mediator-1.12.1.sig ontap-mediator-1.12.1
----
