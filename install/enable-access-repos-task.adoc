[role="lead"]

.단계
. 다음 표에 나와 있는 대로 액세스해야 하는 저장소를 결정하십시오:

. ONTAP Mediator가 설치 과정 중에 필요한 패키지에 접근할 수 있도록 위에 나열된 저장소에 대한 접근 권한을 활성화하려면 다음 절차 중 하나를 사용하십시오.
+

NOTE: ONTAP Mediator가 "extras" 및 "optional" 저장소에 있는 Python 모듈에 대한 종속성이 있는 경우  `rhel-X-for-x86_64-extras-rpms` 및  `rhel-X-for-x86_64-optional-rpms` 파일에 액세스해야 할 수 있습니다.

+
.Oracle Linux 10.x 운영 체제용 절차
[%collapsible]
====
운영 체제가 *Oracle Linux 10.x*인 경우 이 절차를 사용하여 리포지토리에 대한 액세스를 활성화하십시오.

.단계
.. 필요한 저장소를 구독하십시오:
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
----
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
----
+
다음 예는 이 명령의 실행을 보여줍니다:

+
[listing]
----
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
Repository 'ol-10-for-x86_64-baseos-rpms' is enabled for this system.
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
Repository 'ol-10-for-x86_64-appstream-rpms' is enabled for this system.
----
.. 활성화된 저장소 목록을 보려면 다음 명령을 실행하십시오:
+
[source, cli]
----
yum repolist
----
+
새로 구독한 저장소가 목록에 나타나야 합니다.

.CentOS 7.x 운영 체제용 절차
[%collapsible]
====
운영 체제가 *CentOS 7.x*인 경우 저장소에 대한 액세스를 활성화하려면 다음 절차를 사용하십시오:


NOTE: 다음 예시는 CentOS 7.6용 저장소를 보여주는 것으로, 다른 CentOS 버전에서는 작동하지 않을 수 있습니다. 사용 중인 CentOS 버전에 맞는 기본 저장소를 사용하십시오.

.단계
.. C7.6.1810 - Base 리포지토리를 추가합니다. C7.6.1810 - Base vault 리포지토리에는 ONTAP Mediator에 필요한 "kernel-devel" 패키지가 포함되어 있습니다.
.. /etc/yum.repos.d/CentOS-Vault.repo 파일에 다음 줄을 추가하십시오.
+
[source, cli]
----
[C7.6.1810-base]
name=CentOS-7.6.1810 - Base
baseurl=http://vault.centos.org/7.6.1810/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
----
.. 활성화된 저장소 목록을 보려면 다음 명령을 실행하십시오:


[source, cli]
----
yum repolist
----
다음 예는 이 명령의 실행 결과를 보여줍니다. CentOS-7.6.1810 - Base 저장소가 목록에 나타나야 합니다.
