= ONTAP Mediator 설치 워크플로 요약
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator 설치에는 설치 준비, 저장소 접근 권한 제공, 설치 패키지 다운로드, 코드 서명 확인 및 ONTAP Mediator 패키지 설치가 포함됩니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"]link:prepare-install.html["ONTAP Mediator 설치 준비"]
[role="quick-margin-para"]
ONTAP Mediator를 설치하려면 모든 필수 조건을 충족해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"]link:enable-access-repos-task.html["저장소 액세스 제공"]
[role="quick-margin-para"]
ONTAP Mediator가 설치 과정 중에 필요한 패키지에 접근할 수 있도록 저장소 접근 권한을 활성화해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3"]link:download-install-pkg-task.html["ONTAP Mediator 설치 패키지를 다운로드하십시오"]
[role="quick-margin-para"]
ONTAP Mediator 다운로드 페이지에서 ONTAP Mediator 설치 패키지를 다운로드하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"]link:verify-code-signature-task.html["ONTAP Mediator 설치 패키지의 코드 서명을 확인하십시오."]
[role="quick-margin-para"]
NetApp은 ONTAP Mediator 설치 패키지를 설치하기 전에 ONTAP Mediator 코드 서명을 확인할 것을 권장합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["다섯"]link:install-mediator-pkg-task.html["ONTAP Mediator 설치 패키지를 설치하십시오."]
[role="quick-margin-para"]
설치 패키지를 다운로드하고 호스트에서 설치 프로그램을 실행하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["6"]link:verify-install-task.html["ONTAP Mediator 설치를 확인하십시오"]
[role="quick-margin-para"]
ONTAP Mediator를 설치한 후 정상적으로 실행되는지 확인하십시오.
